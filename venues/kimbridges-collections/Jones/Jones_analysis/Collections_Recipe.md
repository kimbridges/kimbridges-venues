# Recipe: Adding a New Collection to kimbridges-collections

A step-by-step guide for adding new collection entries to the
kimbridges.info Collections site hosted on Netlify.

**Site:** https://kimbridges-collections.netlify.app  
**Hosting:** Netlify (manual drag-and-drop deploy)  
**Framework:** Quarto (static site generator)  
**Working folder:** `C:\Users\kim\kimbridges-collections\`

---

## Site Architecture

```
kimbridges-collections/
│
├── _quarto.yml          ← Site config (MUST update for each new collection)
├── custom.css           ← Shared styles (update if new CSS classes needed)
├── index.qmd            ← Landing page with grid listing (MUST update)
│
├── gallery.qmd          ← Collection 1: The Gallery Collection
├── Gallery/             ← Gallery assets (images/, pdfs/, audio/, viewer.html)
│
├── jones.qmd            ← Collection 2: The Jones Collection
├── Jones/               ← Jones assets (images/, pdfs/, data/, HTML files)
│
├── [newname].qmd        ← Collection N: pattern repeats
├── [NewName]/           ← Assets for collection N
│
└── _site/               ← Generated by `quarto render` → drag to Netlify
```

---

## Step 1: Prepare the Collection Materials

Organize your collection assets into a folder at the top level of
kimbridges-collections. Use this internal structure:

```
NewCollection/
├── images/              ← Thumbnail and any section images
│   └── thumbnail.png    ← Required: the card image for the index listing
├── pdfs/                ← PDF documents for download or viewing
├── data/                ← CSV, JSON, or other data files
└── [interactive].html   ← Self-contained HTML files (maps, timelines, etc.)
```

**Naming conventions:**
- Collection folder: PascalCase (e.g., `Gallery`, `Jones`, `CoralReefs`)
- The .qmd file: lowercase (e.g., `gallery.qmd`, `jones.qmd`, `coralreefs.qmd`)
- Keep filenames without spaces when possible

**Size consideration:** Netlify supports up to 500 MB per deploy on paid
plans. Keep original scans and large raw files out of the deploy folder.

---

## Step 2: Create the .qmd File

Create `[newname].qmd` at the top level (same level as `index.qmd`).
Use this template:

```yaml
---
title: "Collection Title"
subtitle: "One sentence describing the collection."
date: 2026-05-05
categories: ["AI", "Science", "Other"]
image: NewCollection/images/thumbnail.png
toc: false
---
```

**Required YAML fields:**
- `title` — appears on the index card and as the page heading
- `subtitle` — appears on the index card below the title
- `date` — controls sort order on the index page (newest first)
- `categories` — filter tags shown on index cards
- `image` — path to thumbnail (relative to the .qmd file)
- `toc: false` — keeps the page clean (optional but recommended)

**Page content follows the YAML header.** Use these patterns:

### Hero Image
```markdown
![](NewCollection/images/thumbnail.png){.hero-image}
```

### Section Dividers
```markdown
::: {.collection-section}
## Section Title
Content here...
:::
```

### Objective Boxes (blue left border)
```markdown
::: {.objective}
**Objective:** What this component demonstrates or tests.
:::
```

### Quote Blocks (orange left border — Jones style)
```markdown
::: {.jones-quote}
"Quoted text here."
<span class="attribution">— Source, date</span>
:::
```

### Embedded Interactive HTML
```html
<iframe src="NewCollection/interactive_page.html"
  width="100%" height="800px"
  style="border: 1px solid #ddd; border-radius: 6px;"></iframe>
```

### File Download Links
```markdown
- [Document Name (PDF)](NewCollection/pdfs/document.pdf)
- [Data File (CSV)](NewCollection/data/datafile.csv)
```

### Embedded PDF Viewer
If using the Gallery's viewer.html:
```html
<iframe src="Gallery/viewer.html?pdf=../NewCollection/pdfs/document.pdf"
  width="100%" height="700px"
  style="border: none; border-radius: 6px;"></iframe>
```

### Placeholder for Future Sections
```markdown
::: {.placeholder-note}
Under development. Description of what will go here.
:::
```

## Step 3: Update index.qmd

Add the new .qmd filename to the listing contents:

```yaml
---
title: "Collections"
listing:
  contents:
    - gallery.qmd
    - jones.qmd
    - newname.qmd        ← Add new entry here
  sort: "date desc"
  type: grid
  grid-columns: 3
  image-height: auto
  categories: true
  fields: [image, title, subtitle, categories]
  filter-ui: false
  sort-ui: false
---

Curated sets of work where one idea spawns the next.
```

**Note:** The `sort: "date desc"` setting means newest collections
appear first. Set the `date` field in your .qmd accordingly.

---

## Step 4: Update _quarto.yml

Add the new collection's resources so Quarto copies them to `_site`:

```yaml
project:
  type: website
  output-dir: _site
  resources:
    - Gallery/pdfs/**
    - Gallery/audio/**
    - Gallery/images/**
    - Gallery/viewer.html
    - Jones/images/**
    - Jones/pdfs/**
    - Jones/data/**
    - Jones/Jones_Collection_Gallery.html
    - Jones/jones_timeline.html
    - Jones/sea_otter_map.html
    - NewCollection/images/**       ← Add these
    - NewCollection/pdfs/**
    - NewCollection/data/**
    - NewCollection/[any].html
```

**Critical:** Any file not listed in `resources` will NOT be copied to
`_site` and will be missing from the deployed site. List every file
type and interactive HTML file explicitly.

## Step 5: Update custom.css (if needed)

Only needed if the new collection introduces visual elements not
already covered. Current available styles:

| Class | Effect |
|-------|--------|
| `.hero-image` | Full-width image with rounded corners |
| `.section-image` | Section illustration, contained height |
| `.collection-section` | Top border divider between sections |
| `.objective` | Blue left-border callout box |
| `.jones-quote` | Orange left-border quote block |
| `.placeholder-note` | Yellow left-border "under development" note |
| `.video-container` | 16:9 responsive video wrapper |

To add a new quote style for a different collection, follow this pattern:

```css
.newcollection-quote {
  background: #f0f8ff;
  border-left: 4px solid #2e86c1;
  padding: 0.75rem 1rem;
  margin: 1.5rem 0;
  font-style: italic;
  color: #2c3e50;
  line-height: 1.65;
}

.newcollection-quote .attribution {
  display: block;
  font-style: normal;
  font-size: 0.85em;
  color: #999;
  margin-top: 0.5rem;
  text-align: right;
}
```

---

## Step 6: Render and Deploy

From the `kimbridges-collections` folder:

```
quarto render
```

This rebuilds the `_site` folder with all collections.

**Verify locally** by opening `_site/index.html` in a browser. Check:
- Index page shows the new card with thumbnail, title, subtitle
- Clicking the card opens the collection page
- All embedded iframes load correctly
- Download links work
- Images display properly

**Deploy to Netlify:**
1. Open https://app.netlify.com/projects/kimbridges-collections
2. Go to Deploys
3. Drag and drop the `_site` folder onto the deploy area
4. Wait for "Published" confirmation
5. Verify at https://kimbridges-collections.netlify.app


## Working with Claude in Cowork

When building a new collection with Claude in Cowork mode:

1. **Mount the collection working folder** as the workspace so Claude
   can access source materials.

2. **Share these reference files** at the start of the session:
   - This recipe (so Claude knows the site structure)
   - The existing `_quarto.yml` and `custom.css`
   - An example .qmd file (e.g., `jones.qmd` or `gallery.qmd`)

3. **Claude can produce:**
   - The collection .qmd page
   - Updated `index.qmd`, `_quarto.yml`, and `custom.css`
   - Interactive HTML files (timelines, maps, galleries)
   - Data extractions and visualizations
   - The organized asset folder

4. **You handle:**
   - Copying files to `kimbridges-collections`
   - Running `quarto render`
   - Drag-and-drop deploy to Netlify
   - Thumbnail creation (AI art from source material)
