## Threads
1. **The scene (concrete, first-person).** Visiting team studies a country's plants, goes home; the host is
   left waiting for the labels, "which comes late, or in pieces, or never."
2. **Name it without grievance (Kim's directive).** "There's a word for the shape of this, and it's
   colonial." Then turn the cause to **structure, not malice**: "It's the same friction this whole book has
   been about." (Kim confirmed this is the right level — no blame, name the many friction-related reasons.)
3. **The right standard, blocked by the labels.** A complete copy — data + labeled curation-ready vouchers —
   should stay in the host country before anyone leaves. The barrier was, "of all things, the labels" — a
   clerical chore.
4. **Two levelers.** (a) **Same capture tech** — the instrument is now a phone; "the same in every hand."
   (b) **Same metadata** — open data (public elevation/geology/soil, shared Darwin Core), no paywall/metered
   key. Pays off the "free / keyless" seed from Ch. 3 & Ch. 6: "which looked like a technical preference
   earlier in the book, was this all along."
5. **The architecture serves the ethic.** Label + log made on site → complete record stays local **by
   default**; the "I'll send it later" friction (and excuse) is gone; deck-discovery lets a community find its
   own decks. "What's shared isn't only the tools. It's the expertise."
6. **Personal — purpose found after capability.** "Seeing that mismatch... was the original idea for the
   project, before any of the pieces existed. I didn't set out to build a system of QR cards. I set out to
   level a playing field..."
7. **Close — sharing is completion (Master Theme 5).** "A record isn't finished... until everyone with a
   right to it can hold it." "A small repayment on a large debt." → "The rest of this book is about making it
   real."
